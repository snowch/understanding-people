# Reference terminology audit

8 November 2026. All 136 developed references were checked for vocabulary that needs a plain-English definition, a distinction from an everyday meaning, or a glossary pointer. This is a terminology and navigation audit, not a new review of scientific accuracy or a specialist review.

The glossary now indexes 115 headwords: 24 existing course terms and 91 reference lookups. Implementation intention points to the existing if–then-plan definition. No extra reference pages or graph nodes are created.

## Decisions

- Link technical or easily confused terms at first use; preserve existing definition links and avoid nested citation links.
- Keep clinical vocabulary, trait dimensions, research vocabulary and informal labels distinguishable. A definition is not a diagnostic checklist or a motive detector.
- Explain family boundary ambiguity as uncertainty about family membership or responsibilities, and contrast it with a personal limit.
- Keep one alphabetical glossary with concise meanings, fictional examples and links back to context and the relevant narration.
- Leave ordinary expressions alone where the entry already explains them clearly. Do not add a technical label for every everyday action.
- Preserve all existing lesson text, anchors, note identifiers, recordings, transcripts and audiobook files. The original glossary narration remains the foundation-term tour; reference lookup rows point to their parent lessons.
- Bind each new lookup to its reviewed parent source fingerprint. Source changes require a wording review before rebuilding.

## Verification boundary

The build checks every registered source fingerprint, every return/listening link and exact preservation of the pre-existing spoken teaching extraction. The generated JSON inventory records all 136 reviewed routes. Search and browser checks verify retrieval, keyboard/mobile navigation, no-JavaScript access, filtering and audio preservation; they cannot establish scientific accuracy, diagnostic validity or learning.
